# PAM ET-FxTSMC

MATLAB/Simulink implementation for the manuscript:

**Event-Triggered Fixed-Time Sliding Mode Control of Pneumatic Artificial Muscle-Driven Robots**

## Files

- `Q0107tsmc_egtsmc_egftsmc_final_sensitivity.slx`: Simulink model
- `AAAAA1195_data.mat`: data required by the simulation model

## Simulation settings

- Simulation time: 12 s
- Fixed step: 0.01 s
- Solver: ode4

## Usage

Open the `.slx` file in MATLAB/Simulink and run the model.

The model and controller parameters are provided in the manuscript.
